# Calculadora WinForms

Aplicação de calculadora desktop desenvolvida em C# utilizando Windows Forms.

## Tecnologias
- C#
- .NET
- Windows Forms

## Funcionalidades
- **Operações Básicas:** Adição, Subtração, Multiplicação e Divisão.
- **Validação de Entrada:** Impede erros de sintaxe (como a inserção de múltiplas vírgulas).
- **Inversão de Sinal (±):** Permite alternar rapidamente entre valores positivos e negativos.
- **Controlo de Apagar:**
  - **Backspace:** Apaga o último caractere digitado.
  - **CE (Clear Entry):** Limpa apenas o texto do visor atual.
  - **C (Clear):** Reseta todas as operações e valores armazenados na memória.

## Como executar
1. Clona este repositório:
   `git clone https://github.com/raphaelsoares01/Calculadora-WinForms.git`
2. Abre o ficheiro `Calculadora.slnx` no Visual Studio.
3. Executa o projeto pressionando `F5`.
